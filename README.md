# Clinical Trial Data Intelligence Assistant

## Project Overview

This project is an enterprise-style Clinical Trial Data Intelligence Assistant built using Python, SQL, DuckDB, Streamlit, and LLM concepts.

The project focuses on:
- clinical trial data analysis
- data quality validation
- SQL analytics
- AI-assisted querying
- risk scoring
- dashboard development

---

## Technologies Used

- Python
- Pandas
- DuckDB
- Streamlit
- SQL
- Jupyter Notebook
